# Lexicon of Sound

A searchable lexicon of sound design and film sound language:

- **Film sound language**: theory (Chion, Murch), workflow, mix and delivery, editing, trailer language.
- **Describing + tagging**: words for timbre, texture, motion, pitch, space and mood, and how to tag a sound.
- **Sound learning**: books, essays, films to study, people, standards and podcasts.
- **UCS**: every Universal Category System category and subcategory, with CatIDs.

Open `index.html`, or visit the GitHub Pages site. The data is in `lexicon.json`.

Entries with an amber dot are still waiting for a person to check them.
